Функция времени очага (source time function, STF) — интегральная характеристика очага землетрясения, ~~отображающая скорость выделения~~ аппроксимирующая выделение энергии ~~сейсмического момента~~ во времени. 
Анализ STF позволяет быстро выявлять аномальные сейсмические события, в частности, цунамигенные землетрясения, характеризующиеся ослабленными высокими частотами.[^1]
Один из методов получения STF — SCARDEC [^1], основан на процедуре деконволюции телесейсмических фаз. 
Данный метод так же позволяет оценить тензор сейсмического момента и магнитную магнитуду события. ~~для определения непосредственно STF и характеристик землетрясения нулевого порядка~~ 
Метод был применен для волновых форм со станций принадлежащих GEOSCOPE. В открытом доступе автором метода опубликованы STF для 4364 событий с магнитудой более 5.8 [^2].

Целью работы является создание верифицированного набора данных, объединяющего сырые волновые формы, магнитуды различных шкал и функции STF. 
Были сопоставлены данные из каталога SCARDEC ~~со станций GEOSCOPE~~ и данные с других станций из каталога ISC.

Сформированный набор данных может быть использован для использования в задачах машинного обучения.
