Функция времени очага (source time function, STF) — интегральная характеристика гипоцентра землетрясения, ~~отображающая скорость выделения~~ аппроксимирующая выделение энергии ~~сейсмического момента~~ во времени. 
Один из методов получения STF — SCARDEC [^1], основан на процедуре деконволюции телесейсмических фаз. 
Помимо этого метод позволяет оценить тензор сейсмического момента и соответствующую магнитуду события. ~~для определения непосредственно STF и характеристик землетрясения нулевого порядка~~ 
В открытом доступе автором метода опубликованы STF для ХХХХ событий с магнитудой более Х.Х [^2]



Целью работы является создание верифицированного набора данных, объединяющего сырые волновые формы, магнитуды различных шкал и функции STF. 
Были сопоставлены данные со станций GEOSCOPE и данные с других станций из каталога ISC для одного события.

Полученные данные можно использовать для машинного обучения
