Временная функция источника (source time function, STF) – зависимость скорости изменения сейсмического момента от времени, характеризующая динамику развития очага землетрясения. Один из методов получения STF – SCARDEC[1], основан на процедуре деконволюции телесейсмических фаз. Данный метод позволяет оценить магнитуду, тензор сейсмического момента события, а так же с помощью анализа функций можно предположить интенсивность землятресения(???). Авторами метода опубликованы STF для 2782 землетрясений с 1992 до 2015 [2] … 

Целью работы является создание верифицированного набора данных, объединяющего сырые волновые формы, магнитуды различных шкал и функции STF. Были сопоставлены данные из каталога SCARDEC и данные с других станций из каталога ISC.

Сформированный набор данных может быть использован для использования в задачах машинного обучения.
