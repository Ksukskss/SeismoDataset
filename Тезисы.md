Функция времени очага (Source time function, STF) — интегральная характеристика гипоцентра землетрясения, отображающая скорость выделения сейсмического момента во времени. Один из методов получения  STF — SCARDEC, использует телесейсмические объемные волны для определения непосредственно STF и характеристик землетрясения нулевого порядка. Существующие наборы данных для сейсмических событий сильно ограниченны по параметрам, часто лишены детальной информации о физике очага.

Целью работы является создание верифицированного набора данных, объединяющего сырые волновые формы, магнитуды различных шкал и функции STF. Были сопоставлены данные со станций GEOSCOPE и данные с других станций из каталога isc для одного события.
