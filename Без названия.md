**Предел** — это число $a$, к которому неограниченно приближается переменная величина (функция или последовательность) в процессе её изменения.

Строгое определение (по Коши) для функции:

Число $A$ называется пределом функции $f(x)$ в точке $x_0$, если для любого $\varepsilon > 0$ существует такое $\delta > 0$, что для всех $x$, удовлетворяющих $0 < |x - x_0| < \delta$, выполняется неравенство:

$$|f(x) - A| < \varepsilon$$

Записывается: $\lim\limits_{x \to x_0} f(x) = A$.

Для последовательности: число $a$ — предел последовательности $\{x_n\}$, если $\forall\, \varepsilon > 0\; \exists\, N \in \mathbb{N}$ такое, что $\forall\, n > N$: $|x_n - a| < \varepsilon$.
