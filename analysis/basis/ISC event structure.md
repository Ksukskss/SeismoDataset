#####  2. Блок гипоцентров 
![[Pasted image 20260216225208.png]]

| **Столбец**   | **Полное название** | **Что означает **                                                                                 |
| ------------- | ------------------- | ------------------------------------------------------------------------------------------------- |
| **Date**      | Дата                | Число, месяц и год начала разрыва в очаге.                                                        |
| **Time**      | Время (UTC)         | Время возникновения землетрясения (Origin Time).                                                  |
| **Err**       | Time Error          | Ошибка определения времени (в секундах).                                                          |
| **RMS**       | Root Mean Square    | Насколько теоретическая модель скорости совпадает с реальными наблюдениями. (лучше $< 1.5$ с).    |
| **Latitude**  | Широта              | Географическая широта эпицентра (от -90 до 90).                                                   |
| **Longitude** | Долгота             | Географическая долгота эпицентра (от -180 до 180).                                                |
| **Smaj**      | Semi-major axis     | Большая полуось эллипса ошибок (в км). Максимальная погрешность координат.                        |
| **Smin**      | Semi-minor axis     | Малая полуось эллипса ошибок (в км). Минимальная погрешность координат.                           |
| **Az**        | Azimuth             | Угол наклона эллипса ошибок. Показывает направление, в котором локализация наиболее слабая.       |
| **Depth**     | Глубина             | Глубина очага в километрах. Если стоит буква `f`, глубина фиксирована вручную.                    |
| **Err **      | Depth Error         | Погрешность определения глубины (в км).                                                           |
| **Ndef**      | Defining Phases     | Количество фаз (P, S и др.), которые реально участвовали в расчете координат.                     |
| **Nsta**      | Number of Stations  | Общее количество станций, сообщивших о событии                                                    |
| **Gap**       | Azimuthal Gap       | «Слепое пятно» — самый большой угол между станциями относительно эпицентра (лучше $< 180^\circ$). |
| **mdist**     | Min Distance        | Расстояние до ближайшей к эпицентру станции (в градусах).                                         |
| **Mdist**     | Max Distance        | Расстояние до самой дальней станции (в градусах).                                                 |
| **Qual**      | Quality             | Флаги качества. Например, `p` — решение принято как основное (Prime).                             |
| **Author**    | Автор               | Название агентства (например, `ISC`, `MOS`, `NEIC`, `GCMT`).                                      |
| **OrigID**    | Origin ID           | Уникальный номер именно этого варианта расчета в базе данных.                                     |
##### 3. Блок магнитуд
![[Pasted image 20260216225319.png]]

| **Тип**   | **Название**                     | **На чем основана**                                                                                      | **Особенности и ограничения**                                                                         |
| --------- | -------------------------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **$m_b$** | **Объемная (body-wave)**         | Измеряется по первым вступлениям **P-волн**                                                              | При очень сильных землетрясениях ($> 6.5$)   перестает расти, даже если энергия растет.               |
| **$M_S$** | **Поверхностная (surface-wave)** | Измеряется по самым длинным и амплитудным **поверхностным волнам** (период ~20с).                        | Лучше описывает силу неглубоких событий. Также подвержена насыщению при магнитудах $> 8.0$.           |
| **$M_w$** | **Моментная (moment magnitude)** | Основана на **сейсмическом моменте $M_0$** (площадь разрыва $\times$ смещение $\times$ жесткость пород). | **Золотой стандарт.** Она физически обоснована и никогда не насыщается. Именно её использует SCARDEC. |
| **$M_L$** | **Местная (local / Richter)**    | Шкала Рихтера. Измеряется на коротких расстояниях ($< 600$ км).                                          | Идеальна для слабых местных толчков, но бесполезна для глобального анализа крупных событий.           |
**Nsta — количество станций, по которым усреднялась магнитуда.

##### 4. Блок фаз
![[Pasted image 20260216225348.png]]

| **Столбец**    | **Полное название** | **Что означает**                                                                    |
| -------------- | ------------------- | ----------------------------------------------------------------------------------- |
| **Sta**        | Station             | Код сейсмической станции                                                            |
| **Dist**       | Distance            | Расстояние от эпицентра до станции в градусах                                       |
| **EvAz**       | Event Azimuth       | Азимут от эпицентра на станцию (в градусах).                                        |
| **Phase**      | Phase               | Тип волны (`P`, `S`, `pP`, `PKP` и т.д.).                                           |
| **Time**       | Arrival Time        | Точное время (UTC) регистрации этой волны на станции.                               |
| **TRes**       | Time Residual       | Невязка времени (разница между реальным и расчетным временем прихода).              |
| **Azim**       | Observed Azimuth    | Измеренный азимут прихода волны на станцию (для групп станций).                     |
| **AzRes**      | Azimuth Residual    | Разница между расчетным и измеренным азимутом.                                      |
| **Slow**       | Slowness            | «Медленность» волны (величина, обратная скорости). Важна для определения типа фазы. |
| **SRes**       | Slowness Residual   | Невязка по «медленности».                                                           |
| **Def**        | Defining            | Стоит `D`, если фаза использовалась для расчета координат (надежная фаза).          |
| **SNR**        | Signal-to-Noise     | Отношение сигнал/шум. Чем выше, тем четче волна видна на записи.                    |
| **Amp**        | Amplitude           | Максимальная амплитуда колебаний грунта.                                            |
| **Per**        | Period              | Период волны в секундах.                                                            |
| **Qual**       | Quality             | Характеристика вступления: `i` (impulsive — резкое), `e` (emergent — плавное).      |
| **Magnitude**  | Station Magnitude   | Магнитуда, рассчитанная только по этой конкретной станции.                          |
| **ArrID**      | Arrival ID          | Уникальный идентификатор этой записи в базе ISC.                                    |
| **Agy / Auth** | Agency / Author     | Агентство, которое обработало эту фазу (например, `MOS`, `USGS`).                   |
| **Deploy**     | Deployment          | Тип установки станции (например, временная сеть или постоянная).                    |
| **Lat / Lon**  | Station Lat/Lon     | Координаты самой сейсмостанции.                                                     |
| **Elev**       | Elevation           | Высота станции над уровнем моря (в метрах).                                         |
| **Depth**      | Station Depth       | Глубина датчика (если он в скважине).                                               |
| **PCh / ACh**  | Channels            | Коды каналов (например, `BHZ`, `HHN`). Показывают частоту и ориентацию датчика.     |
